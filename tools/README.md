# Ava Rose content tools

- `carousel.py data.json outdir` renders 1080x1350 carousels (elegant cream/blush, Cormorant + DM Sans). Data format in the script docstring; example `pack2.json`.
- `story.py stories.json outdir` renders 1080x1920 story frames.
- `photos/` faceless graded cover photos (Pexels). `fonts/` OFL fonts.
Requires: python3, playwright (chromium), pillow.
